# BlueDetect

Dispositivo propio basado en Arduino que detecta direcciones MAC Bluetooth de vehículos para realizar estudios origen-destino en infraestructura vial. Los datos capturados se procesan para obtener información sobre los desplazamientos entre puntos de medición.

Características
Detección de direcciones MAC Bluetooth de vehículos en tránsito.
Diseño, ensamblaje y firmware propios sobre Arduino.
Despliegue simultáneo en varios puntos de medición para cruzar registros entre ubicaciones.
Almacenamiento local (SD) y bateria removible con una duracion de 48 horas operativo
